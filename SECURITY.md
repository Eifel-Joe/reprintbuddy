# Security / Sicherheit

## English

**Please do not report security vulnerabilities as public issues.**

Use GitHub's private reporting instead: open the **Security** tab of this
repository and choose **Report a vulnerability**. Describe what you found, how
to reproduce it and which version is affected.

Reprintbuddy runs on your local network (LAN) and must not be exposed directly to the internet
(no port forwarding, no public reverse proxy); use a VPN for remote access. Only the latest
release receives security fixes.

## Deutsch

**Bitte melde Sicherheitslücken nicht als öffentliches Issue.**

Nutze stattdessen die private Meldung von GitHub: Öffne den Reiter
**Security** (Sicherheit) dieses Repositorys und wähle **Report a
vulnerability** (Sicherheitslücke melden). Beschreibe, was du gefunden hast, wie
man es nachstellt und welche Version betroffen ist.

Reprintbuddy läuft im lokalen Netzwerk (LAN) und darf nicht direkt ins Internet gestellt werden (keine
Portweiterleitung, kein öffentlicher Reverse-Proxy); für den Zugriff von unterwegs ein VPN nutzen.
Nur die neueste Version erhält Sicherheitskorrekturen.
